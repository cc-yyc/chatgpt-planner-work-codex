# 技能卡片外观检查

模式：full。范围为本次技能卡片元数据、SVG/PNG 图标和明暗背景预览。沿用现有 YAML/JSON 元数据与 SVG，未引入前端框架或第二套样式系统。原生客户端的卡片布局、悬停及焦点交互不由此包实现。

| 类别 | 实际检查范围 | 结果 |
|---|---|---|
| 字体排版 | 预览中的中文标题、两行简介与英文单词换行 | 英文按完整单词换行；标题和正文不裁切 |
| 表面与层次 | 浅色/深色预览背景、边框与间距 | 使用中性灰，边框保持低对比，不添加装饰阴影 |
| 动画 | 本包没有动画或交互组件 | 不适用；未审查客户端动画 |
| 图标 | SVG、400×400 PNG 及 16/24/32/48 px 显示 | 统一圆角端点；终端符号与文档线条保持一致的视觉重量 |
| 性能 | 两个本地图标资源与展示元数据 | 不新增脚本、网络服务或界面运行时依赖 |

| 严重度 | 位置 | 原状态 | 修改后 | 原因 |
|---|---|---|---|---|
| LOW | [图标](../../skills/chatgpt-planner-work-codex/assets/planner-icon.svg) | 蓝色文档和勾选标记 | 蓝色文档和深色终端 `>_` | 对应用户追加的规划与 Codex 执行视觉组合，避免仅靠文字说明 |
| LOW | [元数据](../../skills/chatgpt-planner-work-codex/agents/openai.yaml) | 名称“项目规划助手” | “项目规划助手 · Codex” | 在原生卡片支持的字段内标明组合定位 |
| LOW | [预览](icon-preview.png) | 带蓝灰倾向的辅助文字和边框 | 中性灰文字与黑白灰背景，保留蓝色识别 | 让图标成为主要色彩焦点，减少装饰色干扰 |

实际考虑后未采用的方案：不叠加官方品牌标志，因为目标是工作流组合且没有必要复制品牌图形；不在预览中添加可点击的执行按钮，因为技能卡片元数据不提供这种交互入口。

验证方式：本地渲染 SVG 为 PNG，打开明暗背景及不同尺寸的检查图，运行 `python scripts/validate_package.py` 和系统技能格式校验器；检查原规则、默认提示词及调用策略与 1.0.0 基线一致。

结论仅覆盖上述静态外观：Approve。原生卡片的实际尺寸、当前窗口缓存刷新、悬停与键盘焦点效果未验证，不能由预览图推断。
