# 协作流程

```text
用户目标 → 普通 Chat 或 Work 讨论、研究和规划
→ 六字段交接 → Codex 核实环境、实施、验证
→ 证据反馈 → 普通 Chat 或 Work 验收与复审
```

Codex 收到清晰的直接实施请求，可复用已有确认范围并从环境核实开始。用户只要讨论、计划或复审时停在相应阶段，不强制推进流程。

规划端决定目标、范围、方案、设计方向及验收标准；执行端负责真实环境事实、实现细节、项目变更与验证证据。两端遇到矛盾时说清影响，不以静默重定义目标解决。

默认一个上下文、一次有效交接，不创建成套流程文件。派发、实施、验证与验收是不同状态；任何一步只能依据实际回执或证据报告。自动传递不可用时由用户复制，不假装任务已经运行。

分析深度按 [模式选择](workflow-selection.md) 调整；实现与复审分别遵守 [执行协议](executor-protocol.md) 和 [复审协议](reviewer-protocol.md)。历史文档只作为兼容资料，显式保存按 [可选产物](optional-artifacts.md) 处理。
